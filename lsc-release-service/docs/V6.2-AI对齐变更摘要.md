## 二、关键Bug修复（P0）

### 2.1 释放速率计算公式错误

**文件**: `ReleaseService.java`

**问题**: 原代码公式为 `rate = rateMax - alpha × k`，截距取值 0.06%，导致在 k=0.5%（调节起点）时计算结果为 0.03%（下限值），与文档第九章公式不一致。

**修复**: 按文档公式 `rate = 0.09% - 0.06 × k` 修正，截距 = rateMax + rateMin = 0.06% + 0.03% = 0.09%。

```java
// 修复前（错误）
BigDecimal rate = rMax.subtract(alpha.multiply(k));

// 修复后（正确）
BigDecimal intercept = RATE_MAX.add(RATE_MIN); // 0.09%
BigDecimal rate = intercept.subtract(alpha.multiply(k));
```

**影响**: 释放速率在全区间内计算结果偏差约50%，直接影响每日LSC释放量。

### 2.2 释放速率硬常量未固化

**文件**: `ReleaseService.java`

**问题**: rateMax/rateMin 从 `@Value` 配置读取，可通过修改配置文件或数据库覆盖，违反文档18.4节"硬常量固化"要求。

**修复**: 新增 `public static final` 常量，所有计算强制引用常量，配置值仅作为信息展示：

```java
public static final BigDecimal RATE_MAX = new BigDecimal("0.0006"); // 0.06%
public static final BigDecimal RATE_MIN = new BigDecimal("0.0003"); // 0.03%
```

### 2.3 释放速率越界未终止

**文件**: `ReleaseService.java`

**问题**: 原代码越界时仅做截断（clamp），未按文档9.1节要求"直接终止当日释放任务"。

**修复**: 二次校验越界时抛出 `BusinessException`，终止释放流程：

```java
if (rate.compareTo(RATE_MAX) > 0 || rate.compareTo(RATE_MIN) < 0) {
    throw new BusinessException(ErrorCode.K_OUT_OF_RANGE.getCode(),
            "释放速率越界，终止当日释放任务");
}
```

### 2.4 LSC流水幂等键缺失

**文件**: `LscAccountService.java`

**问题**: schema要求 `lsc_transaction.idempotent_key` 为 NOT NULL + UNIQUE INDEX，但 transfer 方法未设置该字段，导致插入失败。

**修复**: 为转出/转入流水分别生成幂等键：

```java
outTx.setIdempotentKey(orderNo + "-" + fromUserId + "-OUT");
inTx.setIdempotentKey(orderNo + "-" + toUserId + "-IN");
```

## 五、服务层变更

### 5.1 ReleaseService
- `calcRate()`: 修正公式为 `rate = 0.09% - 0.06 × k`
- `getConfig()`: rateMax/rateMin 改为引用硬常量
- 新增 `getConfigDecimal()`: 从key-value表读取配置
- 新增 `upsertConfig()`: 配置项插入或更新
- `updateConfig()`: 仅允许修改 kMin/kMax/alpha

### 5.2 LscAccountService
- `transfer()`: 所有流水设置 `idempotentKey`

### 5.3 NhService
- 核销记录填充 `idempotentKey`, `availableBefore/After`, `fundBefore/After`, `version`

### 5.4 B2bService
- `createOrder()`: 填充 `idempotentKey`, `version`, `expireAt`(7日过期)
- `confirmOrder()`: 填充 `confirmedBy`, `confirmedAt`, `counterpartyConfirmed`, `lscTransferred`

### 5.5 OrderService
- `refund()`: 退款时记录 `refundRmbAmount`, `refundLscAmount`, `completedAt`

### 5.6 ProductService
- `aiReview()`: `setAiTags()` → `setAiReviewTags()`（字段重命名适配）

### 5.7 LscApplication（主启动类）
- 新增 `@EnableAutoConfiguration(exclude = {SystemMetricsAutoConfiguration.class, MetricsAutoConfiguration.class})` 修复Cgroup NPE
