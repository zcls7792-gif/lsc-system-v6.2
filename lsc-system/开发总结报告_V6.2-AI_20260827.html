项目概述与交付范围
Overview & Scope

01项目背景

链盛通LSC消费权益凭证循环系统 V6.2-AI 是一套"人民币消费 → 等额LSC凭证发行 → 双池动态释放 → 多场景消费/流转/核销"的闭环系统,支持8大运营AI Agent、双重审核、风险熔断等高级特性。

02本轮交付范围

在完成四端HTML前端初版开发与模态框系统替换后,本轮用户选择"全方向",四大增强方向同步落地:

数据图表与看板4 新图表
AI展示深化3 新模块
业务流程闭环2 张流程图
UI视觉打磨7 新动画

03涉及文件

  • platform-admin/index.html  平台管理后台 · 图表函数、看板、AI中心、B2B状态机
  • shared/design-system.css  共享设计系统 · 动画增强、卡片动效、交错入场
  • mobile-app/index.html  移动端APP · 商品详情动态化、Toast提示(本轮前完成)
  • mini-program/index.html  微信小程序 · 商品详情动态化(本轮前完成)
  • merchant-admin/index.html  商家管理后台 · alert替换为modal(本轮前完成)
技术栈: 纯 HTML5 + CSS3 + 原生 JavaScript(ES6+) · 零构建工具 · SVG 图表 · CSS 变量 · 高兼容性自适应 · 可直接静态部署

3.2B2B订单生命周期状态机

位置:L1242-L1320,B2B订单页顶部。

SVG 920×160 有限状态机可视化:

  • 5 个正常状态(绿色实线箭头):创建订单 → AI核验中 → 对手方确认 → LSC流转 → 已完成
  • 2 个异常终止(红色虚线节点):
    • 匹配度 < 50% → "人工虚假"拒绝回退
    • 对手方拒绝 → "已驳回"分支
  • 风控熔断旁路(灰色虚线路径):LSC流转阶段若触发风控,可退回AI核验中重新校验
  • 状态标签色:蓝=处理中、黄=待确认、绿=完成、红=异常(虚线描边区分)
合规价值: 状态机图示为订单纠纷追溯与审计提供了直观参照,明确"哪些操作会导致什么状态变化"。

API & Code Reference

5.1图表函数签名

// 环形图 (支持引线标签 + 中心总计) function donutChart({ w, h, data:[{label,value,color}], inner=0.55, unit='' }) → SVG string // 热力图 (单元格渐变透明度 + 高值显示数字) function heatmap({ w, h, rows, cols, data:[[v],...], colorBase }) → SVG string // 堆叠柱状图 (返回 {svg, legend} 两部分以便独立布局) function stackedBar({ w, h, labels, stacks:[{name,color,data:[]}], unit }) → Object // 雷达图 (多系列对比 + 4层同心圆网格) function radarChart({ w, h, labels, series:[{name,color,data:[]}], max=1 }) → SVG string // 进度环 (单个百分比指标) function ringChart(pct, color) → SVG string

5.2移动端/小程序新增函数

// 共享商品数据 (6 项完整商品,含AI评分/库存/描述) const PRODUCT_LIST = [{ name, price, tag, merchant, sales, cat, aiScore, stock, desc }, ...] // 打开指定商品详情 → 切屏 function openProduct(idx) → 调用 renderProduct(idx) + showScreen('product') // 按索引渲染商品详情页 (价格/库存/AI评分双卡/描述/加购/购买) function renderProduct(idx) → 填充 #screen-product // Toast 轻提示 (中心位置,2.2s 自动消失) function showTip(msg) → DOM 插入 #app-tip,带淡入淡出 // 加入购物车 → 触发带商品名的 Toast function addToCart(idx)

5.3模态框系统 (四端统一)

函数用途典型场景
openModal({title, body, footer, danger, onClose})通用弹窗底层详情页、配置表单
closeModal()关闭全局弹窗按钮/遮罩/关闭图标
resultModal(title, body, level)操作结果提示视频上传、保存草稿、凭证上传
confirmModal(title, desc, onConfirm, opts)二次确认核销申请、B2B订单提交
dualApprovalModal(title, body, onApproved)双重审批(双人)参数调整、处罚执行(平台)
零 alert 原则: 本轮完成后,4 个前端应用代码中 alert() 调用点为 0,全部替换为模态框或 Toast。

后续改进与规划建议
Roadmap & Recommendations

7.1短期可扩展 (P0 · 1-2 天)

  • 商家后台图表补齐:将平台后台的 donutChart/stackedBar 复用至商家后台,增加商家个人核销趋势、商品销售分布等专属图表
  • C端LSC流转可视化:移动APP/小程序的"我的钱包"页,为单个用户绘制迷你流转链路(消费→锁定池→释放记录→消费抵扣)
  • 活动流自动刷新动画:AI Agent活动流用 setInterval 每10秒追加一条随机新记录,顶部插入带 slideDown 动画,模拟真实推送
  • 释放速率图表真·实时:用 window.setInterval 每 3 秒 append 新采样点到 lineChart series,旧点左滑出视野

7.2中期功能 (P1 · 3-5 天)

  • 订单生命周期单条追踪页:点击B2B订单行打开详情,以时间轴+状态机联动方式显示该订单的完整流转记录(谁/何时/做了什么操作)
  • 双池资金溯源 Sankey 图:将 donutChart 改为桑基图,展示锁定池→可用池→核销/B2B/过期 的资金流量分配
  • 图表导出:SVG→PNG,增加"导出看板截图"一键功能(可借助 canvas.toDataURL 纯前端实现,无需后端)
  • 深色模式:CSS 变量增加 [data-theme="dark"] 配色,通过切换属性切换主题,图表颜色自适应

7.3长期演进 (P2 · 超过1周)

  • 接入真实后端数据:将 MOCK 对象替换为 fetch('/api/...') 调用,增加数据加载 skeleton 骨架屏占位
  • WebSocket 实时推送:活动流、订单状态变更、风险告警替换为服务端推送,而非前端 setInterval 轮询
  • 多角色权限:超级管理员/运营/商家/用户四级角色控制可见菜单与操作按钮,避免硬编码 UI
  • 单元测试:图表函数、模态框、状态机逻辑抽象为模块,补充 Vitest/Jest 单元测试 + jsdom 断言
