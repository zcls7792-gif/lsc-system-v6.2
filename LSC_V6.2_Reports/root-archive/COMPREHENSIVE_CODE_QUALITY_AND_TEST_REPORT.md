| **🟢 低危** | @Valid 缺失 | 75处 | Controller 层输入未显式校验 |

> **注**: 初始报告中的「1处 SQL 拼接风险」经深入排查确认为**误报**。项目全面使用 MyBatis-Plus `LambdaQueryWrapper`（80处）、`BaseMapper`（50个接口）及 XML `#{}` 参数化查询，无任何 SQL 注入风险。同时已新增 `SqlInjectionGuard` 安全工具类作为防御性加固。
